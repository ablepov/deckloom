20 октября 2026 года. Статус: B2 реализован и проверен локально. Разрешено: реализация B2 по [контракту B1](../contracts/project-deck-slide-v1.md), нейтральные примеры и проверки. B3–B4, потребители и Monq вне области задачи. Существующие незакоммиченные изменения A/B1 сохранены. Ветка master, без commit/push/publish; номер версии не меняется.

## Реализация

- Внутренний src/project.cjs: normalizeProject создаёт неизменяемое описание engine metadata, preflightProject проверяет выбор операции и файловые пути без записи. Модель не является сохраняемым документом и не экспортируется через package exports.
- Registered и discovery проверяются раздельно. Есть закрытые поля v1, обязательные массивы, строгие типы и null/undefined, ID с ASCII case-insensitive уникальностью, независимые оси размеров, expectedSlides, profile/prefix/artifactNo и drafts. Индексы/номера вычисляются из авторского порядка; ID не генерируется из позиции.
- Непрозрачные data не сериализуются, не клонируются и не замораживаются. Нормализация не меняет исходный конфиг. Состав/порядок/размеры engine metadata фиксируются для операции; ссылки на данные адаптера остаются исходными.
- Legacy bridge различает все-slides / все-discovery, отвергает неоднозначный mixed/пустой legacy input, сохраняет цифровые no и исходные объекты для callbacks. Относительные legacy paths разрешаются в одном месте от cwd, диагностика доступна во внутренней модели. Миграция конфига/файлов автоматически не выполняется.
- Stable/legacy пути проверяются на границы root/outputRoot через существующие realpath symlink/junction и ближайший существующий предок ещё не созданного пути. Prefix/reportName/path aliases и существующие файлы вместо каталогов выявляются до записи; имена отчётов разрешаются для всех колод Project. Отдельный outputRoot также не может подменить другой исходный артефакт. Сопоставление использует индексы путей и родителей, без попарного сравнения всех слайдов. Проверки не гарантируют неизменность файловой системы другим процессом после preflight.
- Публичные прежние renderer/server/scanner используют один validation/preflight. Renderer исполняет подготовленный план; callback не меняет текущие пути, порядок и viewport. Для --deck=all план общий для всех выбранных колод; не появляется новая колода, добавленная callback-ом.
- writeArtifact создаёт уникальный временный файл через exclusive open: чужой temp/result не перезаписывается при совпадении имени и не удаляется после неудачного открытия. Публикация артефакта по-прежнему выполняется одним rename.
- Ошибки — обычные Error с code, field и при наличии deckId/slideId; общий публичный error/result контракт C2 здесь не вводится.

Версионированный конфиг проходит внутреннюю нормализацию/preflight в нейтральных тестах. Во внешних facades его исполнение явно отклоняется CONTRACT_RUNTIME_PENDING после структурной проверки. HTTP payload, discovery scan, состав viewer и состояния HTML/PNG не переведены на v1. B4 по-прежнему должен согласовать effective dimensions и состояния во всех представлениях; использование snapshot viewport в renderer не меняет scanner/API/viewer.
