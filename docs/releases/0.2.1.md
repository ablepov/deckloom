# Deckloom 0.2.1

This patch improves the viewer toolbar and the existing download workflow.

- Individually vendored Lucide layers, layout-grid, download, loader-circle and chevron-down SVG geometry replaces the previous toolbar artwork. The source commit, hashes and full license are included; no icon library runtime dependency or CDN request is added.
- While an export runs, the download button shows a rotating loader and "Готовим…", with a stable width and accessible busy state. The mobile toolbar retains the loader; reduced-motion disables rotation. Success and failure restore the normal icon and label.
- Download menus stay above export notifications, so a ready/error notice no longer blocks another export selection.

Install with `npm install deckloom@0.2.1 --save-exact` and restart the viewer. No consumer configuration or document migration is required. Export formats and temporary job retention are unchanged.

Validation and rollout: [toolbar task](../tasks/toolbar-icons-2026-10-22.md).
