# Deckloom 0.2.0

This release adds deck downloads to the viewer and publishes the engine APIs developed since 0.1.0. Slide content, brand assets, font files and consumer export profiles remain in the consuming project.

- Viewer menu: PDF, editable PPTX, or ZIP with PPTX and licensed source fonts for the selected whole deck. Google Slides is a disabled Beta placeholder; no upload or Google authentication is implemented.
- Background export jobs expose progress, errors, retry and repeat download. Results are temporary (30 minutes, at most eight completed jobs). Reloading the viewer currently loses its job association; server restart removes the jobs. Persistent job recovery is not part of this release.
- Versioned Project/Deck/Slide and read/runtime APIs, immutable build publication, portable PNG/PDF/HTML exports and bounded editable PPTX profiles.
- Presentation documents, pinned template catalogs, typed fields/compositions, immutable editing helpers and atomic local storage with recovery.
- Shared semantic HTML capture, measured text geometry and source-font transport. Complex consumer scenes may be exported as local images while supported text and fills remain editable. Exact cross-application font shaping is not guaranteed.
- PDF validation accepts self-contained Type3 glyph programs and still requires embedded streams for ordinary fonts.

## Consumer update

Install the exact version with `npm install deckloom@0.2.0 --save-exact`, commit the resulting dependency and lockfile changes according to the consumer's workflow, and restart the normal viewer. Existing render configurations retain their entry points. See the [migration guides](../migrations/) for the versioned APIs and explicit export profiles.

The download menu uses the optional `Project.downloads` namespace. PDF needs a registered renderable deck. PPTX and font ZIP require supported export configuration; fonts require explicit redistribution permission, pinned bytes and license files. See the [download contract](../contracts/viewer-downloads-v1.md). No fonts are installed automatically.

For Monq, native PPTX and font ZIP are configured for Retail16. PDF is available for registered renderable decks. Other Monq PPTX profiles remain outside this release's consumer configuration.
