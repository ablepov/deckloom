# Deckloom 0.3.0

This release supports publishing a prepared presentation for viewing without a local authoring server.

- `publications` provides a versioned, data-only manifest/catalog, validation, file integrity checks and mappings to the existing viewer/download API. `prepare` produces an isolated PNG/PDF bundle from one offline generation, with optional native downloads when the consumer's export profile supports them.
- `viewer.renderPage` and `viewer.asset` let applications host the canonical viewer. A published viewer pins its release, stops authoring polling and downloads ready files without starting export jobs.
- Optional point comments bind normalized coordinates to stable slide IDs and generated revisions. The library supports portable JSON/ZIP exchange and a local adapter. Consumers own user access, storage, HTTP integration and rollout; installing the package does not enable anonymous comments.

Existing rendering and export APIs remain available. No S3 client, credentials, corporate assets, presentation content, hosted service or database migration is shipped by the engine. Consumer export profiles still determine native PPTX support.

Install with `npm install deckloom@0.3.0 --save-exact` and restart the consumer process. Publication and comment protocol versions are separate from the npm version.
