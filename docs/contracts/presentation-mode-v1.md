# Ручной режим показа v1

Общий viewer Deckloom; локальный и published hosts используют одну реализацию через `viewer.renderPage`. По умолчанию показ включён; `Project.viewer.presentation:false` или renderer config `presentation:false` отключает кнопку/слой. Настройки не ослабляют доступ к данным и статический профиль слайдов.

## Сценарий

«Запустить презентацию» начинает с выбранного слайда; при первом открытии без сохранённой позиции выбран первый. Запрос fullscreen выполняется синхронно с действием пользователя, до await загрузки. В fullscreen/оконной поверхности сначала показана подготовка с прогрессом и отменой. Сам показ начинается после готовности всей колоды. Ошибка называет номер слайда, доступны повтор подготовки того же снимка или выход.

Если стандартный API отсутствует, запрещён Permissions-Policy или отклонил запрос, явно сообщается «Показ в области окна». Во вложенном viewer эта область ограничена iframe; это не обещание fullscreen всего устройства. Host делегирует `fullscreen` только нужному viewer и не расширяет доступ к материалам. Browser exit обрабатывается через `fullscreenchange`; клавиатурный Escape и кнопки выхода/отмены используют ту же идемпотентную очистку.

Показывается весь canvas с индивидуальными width/height, без обрезки и растяжения, с тёмными полями. Resize, ориентация и DPI не меняют авторскую геометрию. ←/PageUp назад, →/PageDown/Space вперёд. Начало/конец ограничены, без зацикливания, таймера и автоматического выхода. Autorepeat не перелистывает цепочку. Обычный viewer сохраняет прежнюю циклическую навигацию.

Ввод/IME и браузерные shortcuts с modifiers не перехватываются. Space на button/link сохраняет обычное действие. Tab/Shift+Tab доступны для controls; HTML frame сохраняет ввод и собственный порядок фокуса. Колесо не перелистывает; browser zoom с Ctrl/Meta не блокируется. Touch использует явные кнопки; swipe и orientation lock не добавлены. Controls и подсказка вместе скрываются через 2,5 секунды бездействия указателя, возвращаются при движении/касании/фокусе. Касание canvas только раскрывает управление. Клавиатурный ввод и фокус на controls сохраняют управление видимым; touch targets не меньше 44px, safe-area и место под controls сохраняются даже в скрытом состоянии. Подготовка, ошибка и повтор не скрываются. Переходов между слайдами нет. Для chrome используются opacity и небольшое смещение; reduced motion отключает переходы и смещение.

Запуск — компактный icon-only Play с title/accessible name «Запустить презентацию». Цвет задаётся CSS-переменной `--presentation-accent`, fallback `#ffa34d`. Стрелки/крестик и отдельный овальный счётчик используют небольшие тёмные полупрозрачные подложки с необязательным blur; читаемость не зависит от поддержки blur.

После выхода сохраняются последний слайд, прежний focus/overview режим; фокус возвращается после завершения native fullscreen exit. Overview открывается возле последнего показанного слайда. Перезагрузка не восстанавливает fullscreen автоматически.

## Ресурсы и версии

При входе копируются выбранные slide DTO/order/dimensions; новые read-запросы приостановлены, уже отправленные abort/epoch-защитой не могут применить ответ. Hashchange не переключает колоду во время показа. Подготовка предпочитает available PNG как в v1 (artifacts.png), так и legacy (url без imageError); opaque legacy version не является SHA-256. HTML используется, когда пригодного PNG нет. Для published PNG SHA-256 сверяется с version/hash, размеры v1 — с canvas. Compressed image bytes удерживаются в object URLs до выхода; изображения предварительно декодируются для проверки. URL освобождаются при отмене/повторе/выходе. PNG-навигация после подготовки работает без сети в открытой вкладке; офлайн-перезагрузка страницы не поддерживается.

HTML-only загружается существующим `loadDocumentFrame`: тот же static validator и sandbox `allow-same-origin` без scripts. Подготовленные frames остаются в DOM; внутренние ресурсы HTML не превращаются в новый переносимый bundle. Внешние/изменяемые ресурсы и unversioned legacy URL не получают гарантию immutable выпуска. Скрипты, active animations/canvas/video/audio не включаются в статический профиль ради показа. PNG не воспроизводит внутреннюю анимацию. PDF/PPTX/offline export index не изменены.

После выхода локальный viewer проверяет composition без автоматической подмены: при отличии предлагает «Обновить»/«Позже». До явного обновления остаются прежние данные; при сбое есть повтор проверки. Обновление заново читает API и сохраняет текущий slide ID, если он существует. Published viewer сохраняет fixed release API и не включает dev polling.

## Review и exports

Слой показа — отдельный sibling основного app; app становится inert, служебные элементы туда не копируются. До подготовки dispatch `window` CustomEvent `deckloom:presentation`, detail `{active:true}`; после выхода `{active:false}`. Существующий comments bridge сохраняет draft, убирает пины/popover/panel/tools и блокирует C; выход автоматически не открывает review. Storage mutation/закрытие веток не выполняются. Download notices и меню остаются в основном app за непрозрачной поверхностью; экспортные jobs/файлы не меняются.

Композиция, хранилище, авторизация и выдача ресурсов принадлежат прежним contracts/host. Speaker notes, remote control, autoplay, transitions и animation runtime вне v1.
